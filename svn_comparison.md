# Git vs SVN

## 1. Почему в Git ветка «дешевая», а в SVN — «дорогая»?
В Git ветка — это просто указатель на коммит (файл размером несколько байт), переключение мгновенное. В SVN ветка — это копирование директорий на сервере, операция тяжёлая и зависит от скорости сети.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет. SVN — централизованная система: коммит уходит на центральный сервер, без сети операция невозможна. В Git коммит локальный, а `push` можно отложить.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
Legacy-проекты, где вся инфраструктура завязана на SVN, а также проекты с жестким разграничением прав доступа на уровне отдельных папок.
